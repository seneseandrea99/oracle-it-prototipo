# Surface brief: mappa principale (index.html)

Scope: the single map screen of the ORACLE IT prototype. Mode: Operate. Audience: people who want to understand what is happening in Italy, mostly on a phone. Job: in three seconds see where things happen, how serious, and why it is trustworthy. Success per owner: wow effect, clarity in 3 seconds, trust. Must not read as a traffic app, an institutional site, or militant.

## Direction contract
FORM: owner-pinned direction ("strumento di intelligence da videogioco, tipo Watch Dogs"), overriding roll seed:1ce46091179b2b95 (degraded, no challengers).
THESIS: an intelligence HUD over the real map of Italy that scans events, never people; refuses the category default of a dark map with coloured pins and a list.
OWN-WORLD: monochrome near-black map recoloured to white linework and low white 3D building wireframes; white ink, one cyan system signal; red/amber/teal only for event states. Display face Chakra Petch, body Atkinson Hyperlegible, data in Martian Mono. Corner-bracket frames instead of cards, hairline rules, square controls.
STORY: the visitor sees Italy under scan, picks an event, the system locks on and shows the evidence trail: sources stacking as packets, an integrity meter, the timeline.
FIRST VIEWPORT: shell first: top status strip (name, synthetic-data tag, live counters), filter bar, full-bleed tilted map, bottom panel (phone) or left column (desktop) with the event list.
SIGNATURE MOVE: lock-on. Selecting an event snaps corner brackets onto its map point, decodes its label, and draws a leader line from the point to the panel, where sources arrive one by one as numbered packets filling an integrity meter.
RISK: costume of a game UI hurting readability; held to type, palette, density and the lock-on, with standard controls.
